How the ranges are built

Past daily returns are rescaled to today's volatility and resampled in one month blocks, thousands of times.
Each range was checked walk forward on 93 stocks and ETFs: forecasts made with only the data available at the time, scored against what actually happened.
There is no price target here. A point forecast model was tested and did not beat a simple average, so it is not shown. Past prices only, no dividends, not financial advice.
